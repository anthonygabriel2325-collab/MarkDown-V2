Markdown V2 (MD2) - Especificação & Playground
Uma especificação moderna e parser conceitual para uma evolução do Markdown tradicional. O MD2 foi criado para trazer interatividade nativa, micro-estilos, animações e layouts avançados diretamente na sintaxe, sem a necessidade de recorrer a marcações complexas em HTML.

🚀 Recursos Principais
Formatação Inline Avançada: Suporte nativo para destaque (==texto==), sublinhado (__texto__), texto tachado (~~texto~~), expoentes/subscritos (x^2^ e H~2~O), atalhos de teclado ([[Ctrl]]) e spoilers interativos (||[spoiler]||).

Micro-Estilos Flexíveis: Personalize cores, fontes, tamanhos, espaçamentos e efeitos de hover dinâmicos usando sintaxes intuitivas como [Texto]{color=yellow size=1.5em}.

Animações Nativas: Adicione efeitos visuais fluidos facilmente com atributos como animate="rainbow", animate="pulse" ou animate="typewriter".

Blocos Especiais & Layouts: Estruture conteúdos complexos com blocos focados em leitura (:::book), caixas de aviso (:::info, :::danger), colunas flexíveis e abas interativas (:::tabs).

🛠️ Como Usar (Playground)
O arquivo principal da biblioteca (index.html) já vem equipado com um playground interativo dividido em duas colunas:

Editor: O painel esquerdo onde você escreve e experimenta a sintaxe MD2 em tempo real.

Preview: O painel direito que compila e exibe o resultado visual instantaneamente.

Para testar localmente:

Baixe ou copie o conteúdo do arquivo index.html.

Abra-o diretamente em qualquer navegador web moderno.
